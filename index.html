Algorithms and Complexity

What is a Doubly Linked List?

A doubly linked list is a linear data structure in which each node stores a reference to the previous and next node. This makes forward and backward traversal efficient and supports insertion and deletion at both ends.

Why it suits playlists

Playlists need fast navigation, insertion, and deletion around the current track. The list structure stores songs in order while allowing easy movement between songs with a current pointer.

Complexity Summary

  • Insert at head: O(1)
  • Insert at tail with tail pointer: O(1)
  • Delete head: O(1)
  • Delete tail with tail pointer: O(1)
  • Search: O(n)
  • Insert at arbitrary position: O(n)
  • Forward traversal: O(n)
  • Backward traversal: O(n)
  • Next/Previous using current pointer: O(1)
  • Storage: O(n)

Pseudocode

if currentNode != null:
    next = currentNode.next
